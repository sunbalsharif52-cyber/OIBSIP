## 📊 <b style="color: #8A2BE2;">Dataset Structure</b>
The analysis was performed on the **Online Retail II** dataset, which contains real transactional records across two major periods:
1. <b style="color: #8A2BE2;">Year 2009-2010</b> (Sheet 1)
2. <b style="color: #8A2BE2;">Year 2010-2011</b> (Sheet 2)

📥 **[Download Raw Dataset (`online_retail_II.xlsx`)](https://archive.ics.uci.edu/ml/datasets/Online+Retail+II)**
*(Note: Due to GitHub's 25MB file size limitations on direct web uploads, the raw Excel dataset is hosted externally. You can download it directly from the official UCI Machine Learning Repository link above).*

**Combined Raw Dataset Shape:** Over 1 million rows and 8 transactional features.
